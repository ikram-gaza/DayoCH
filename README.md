# Dayo CH

Application web de gestion du Capital Humain pour le Groupe Dayo.

## Stack Technique

- **React 19.3.1** - Framework UI
- **Vite 8.3.5** - Build tool
- **Tailwind CSS v4.3.4** - Framework CSS
- **React Router v7** - Routing
- **ReactFlow** - Organigramme interactif
- **Lucide React** - Icônes
- **Axios** - HTTP client

## Design System

Design premium inspiré d'Apple avec :
- Glassmorphism & backdrop-blur
- Ombres multi-layered
- Animations fluides
- Typographie SF Pro Display / Inter
- Couleurs officielles Groupe Dayo

## Filiales

- 🇧🇯 Dayo Bénin (BEN)
- 🇬🇳 Dayo Guinée (GIN)
- 🇧🇫 Dayo Burkina Faso (BFA)
- 🇨🇮 Dayo Côte d'Ivoire (CIV)

## Développement

```bash
# Installation des dépendances
npm install

# Serveur de développement
npm run dev

# Build production
npm run build

# Lint
npm run lint
```

## Modules

1. **Dashboard** - Vue d'ensemble
2. **Organigramme** - Hiérarchie interactive avec historique
3. **Congés** - Gestion des absences
4. **Fournitures** - Gestion du stock
5. **Sollicitations** - Demandes diverses
6. **Statistiques** - Tableaux de bord
7. **Évaluations** - Performance
8. **Formations** - Apprentissage & Quiz
9. **Administration** - Configuration

## Authentification

- Connexion avec email/mot de passe
- 2FA optionnelle (Google Authenticator)
- 4 rôles : employe, manager, gestionnaire_stock, super_admin
