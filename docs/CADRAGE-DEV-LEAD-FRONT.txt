PARTIE I - LECTURE DU DOCUMENT ARBORESCENCE_ET_FLUX
================================================================================

I.1  CE QUI EST JUSTE, ET QUE L ON GARDE

  Le document montre une vraie comprehension de l architecture. A garder tel
  quel, et a valoriser dans l evaluation :
    - trois couches : pages / hooks et services / API, aucune page ne parle
      directement a Axios ;
    - jeton d acces en memoire, jeton de rafraichissement persiste,
      rafraichissement automatique sur 401 ;
    - en-tete X-Filiale-Id et perimetre dans les cles TanStack Query ;
    - invalidation apres creation, mutation, photo, signature ;
    - filtres dans l URL, recherche retardee ;
    - "les guards du front ameliorent l experience, la securite est cote
      backend" : la phrase exacte qu on attend d un developpeur ;
    - la liste des routes deja prevues pour agents, trombinoscope, pilotage
      et organigramme correspond au backend.

I.2  CE QUI CHANGE, ET POURQUOI

  Douze ecarts entre le document et le backend. Chacun est tranche ci-dessous.
  Ils ne sont pas des fautes de debutant : ils viennent presque tous d un
  front construit AVANT que le backend existe, avec des donnees simulees pour
  avancer. Maintenant que le backend tourne, ces simulations deviennent une
  deuxieme verite qui contredit la premiere.

  E1. LES MOCKS D AUTHENTIFICATION (VITE_USE_MOCK_AUTH, totp.js)
      Constat   section 10 : en mode mock, "l identifiant determine le role,
                le mot de passe est ignore". Section 4.3 : des secrets TOTP
                sont stockes dans localStorage (dayoch_2fa_secrets_v1).
      Risque    une variable d environnement mal reglee au build, et
                n importe qui se connecte "admin" sans mot de passe. Un
                secret TOTP dans localStorage est lisible par tout script
                de la page : c est la definition d un second facteur casse.
      DECISION  supprimes. config/donnees.js, utils/totp.js, les comptes de
                demonstration, VITE_USE_MOCK_AUTH, VITE_USE_MOCK_DATA.
                On developpe contre le backend local (npm run seed fournit
                les donnees). Si des tests ont un jour besoin de reponses
                simulees, elles vivront dans les TESTS (MSW), jamais dans le
                code livre aux utilisateurs.

  E2. LES QUATRE ROLES INTERNES (employe, manager, gestionnaire_stock,
      super_admin) ET authMappers.js QUI LES TRADUIT
      Constat   le backend a SIX roles : SUPER_ADMIN, ADMIN_FILIALE, GERANT,
                RESPONSABLE_STOCK, RESPONSABLE_SERVICE, AGENT. La traduction
                en quatre en ecrase deux (ADMIN_FILIALE, RESPONSABLE_SERVICE)
                et invente une equivalence (GERANT = manager ?) que le
                backend ne fait pas.
      DECISION  le front utilise les codes du backend, tels quels.
                shared/auth/types.ts expose la constante ROLES avec ces six
                codes. La couche de normalisation (api-auth.ts) corrige la
                FORME (objets -> codes), jamais le SENS.

  E3. LES PERMISSIONS DEFINIES COTE FRONT (config/permissions.js)
      Constat   le tableau de la section 6.2 utilise pilotage:read,
                trombinoscope:read, organigramme:read, organigramme:export.
                Ces quatre permissions N EXISTENT PAS dans le backend.
                Les ressources du backend sont : filiale, departement,
                service, agent, user, role, categorie, produit, stock,
                mouvement_stock, produit_defectueux, fournisseur, salle,
                equipement, reservation, demande, audit. Les actions :
                create, read, update, delete, validate, export.
                Le trombinoscope et l organigramme sont gouvernes par
                agent:read ; le pilotage n exige aucune permission.
      Verifie   un compte AGENT, connecte au backend reel, voit
                UNIQUEMENT "Pilotage" dans son menu. Le tableau du document
                lui donnait la liste des agents et le trombinoscope.
      DECISION  config/permissions.js supprime. Les permissions viennent du
                serveur (champ `permissions` de /auth/login et /auth/profil).
                useAuth().peut('agent:read') teste ces chaines, rien d autre.
      QUESTION METIER, A TRANCHER PAR LA DIRECTION, PAS PAR LE FRONT :
                "tous les employes doivent-ils voir le trombinoscope ?"
                Si oui, c est une ligne dans le seed des permissions du
                backend (role AGENT + agent:read), et le front suit sans
                modification.

  E4. LE MENU CODE DANS Sidebar.jsx SELON LE ROLE
      DECISION  le menu vient de GET /pilotage/modules. Le serveur le filtre
                deja selon les roles et permissions du compte, et indique
                `disponible: false` pour un module pas encore developpe
                (affiche grise, non cliquable). Le front n a aucune liste
                de modules en dur.

  E5. LES FILIALES EN DUR (config/filiales.js)
      DECISION  supprime. Liste issue de GET /filiales, triee explicitement
                par code (sortBy=code&sortOrder=ASC). Une cinquieme filiale
                ne doit pas exiger une livraison du front.

  E6. LES DONNEES DE DEMONSTRATION (agentsDemo.js, organigrammeDemo.js,
      calcul mock des indicateurs de pilotage)
      DECISION  supprimes. Les indicateurs sont calcules par le serveur
                (GET /pilotage/tableau-de-bord). Les recalculer cote front
                donnerait deux chiffres differents pour la meme question.

  E7. LES MODULES "HISTORIQUES" EN localStorage
      Conges, sollicitations, fournitures, stock, tracabilite, demandes de
      stock, alertes, utilisateurs.
      Constat   le backend n a AUCUNE ressource conges ni sollicitation.
                Il a les entites stock, mouvements, demandes, mais pas
                encore leurs routes. Il a une API complete des comptes
                (/users, /rbac).
      DECISION
        - utilisateurs  -> branche sur /users et /rbac, route /comptes
                           (etape 5.5 du plan d integration)
        - stock, tracabilite, alertes, demandes de stock, fournitures
                        -> GELES. Ils reviennent quand le backend expose
                           leurs routes, sous /stocks et /demandes.
        - conges, sollicitations
                        -> RETIRES de l application. Ce sont des besoins
                           metier legitimes, mais ils commencent par une
                           conception COTE BACKEND (entites, regles, qui
                           valide quoi). Un ecran en localStorage donne
                           l illusion d un module qui n existe pas : un
                           conge "pose" sur un poste n existe sur aucun autre.
        - formations, evaluations, statistiques, parametres ("a venir")
                        -> retires de la navigation pour la meme raison.
      Le code actuel de ces ecrans n est pas jete : il est conserve sur la
      branche git `archive/maquettes-localstorage`. Son interface pourra
      etre reprise le jour ou le backend existera.

  E8. DEUX TABLEAUX DE BORD (/dashboard et /pilotage)
      Constat   le backend a UN module "Pilotage" dont l adresse declaree
                est /tableau-de-bord.
      DECISION  une seule page, /tableau-de-bord. Les elements de
                DashboardPage et de PilotagePage sont fusionnes dedans.

  E9. L ORGANIGRAMME "PAR FILIALE" AVEC GLISSER-DEPOSER ET HISTORIQUE LOCAL
      Constat   dans le backend, l organigramme n est pas un dessin : il est
                CALCULE a partir des affectations des agents. Un deplacement
                dans l organigramme est une MUTATION, qui ferme une periode
                de carriere et en ouvre une autre (historique des postes,
                exigence de la direction). Un glisser-deposer enregistre en
                local ne laisse aucune trace serveur et contredit la fiche
                de l agent.
      DECISION  une seule vue, en lecture seule : GET /organisation/
                organigramme, avec la date de reference (organigramme tel
                qu il etait a une date passee), le pliage des branches et
                les exports serveur. Pour changer quelqu un de place : la
                mutation, depuis sa fiche (PATCH .../mutation).

  E10. LES EXPORTS GENERES COTE CLIENT (utils/export.js)
      DECISION  supprime. Chaque liste a son export serveur
                (GET .../export?format=xlsx|pdf|csv), avec la charte Dayo,
                les filtres rappeles en en-tete, des valeurs typees dans
                Excel et un PDF vectoriel. Un export cote client ne
                contiendrait que la page affichee, pas tout le resultat.

  E11. LES ROUTES DE LA DOUBLE AUTHENTIFICATION
      Constat   section 10 : /auth/2fa/setup, /auth/2fa/enable,
                /auth/2fa/disable. Ces adresses N EXISTENT PAS.
      Reel      POST /auth/2fa/preparer  -> { secret, otpauthUrl, qrCodeDataUrl }
                POST /auth/2fa/activer   { codeTotp } -> { codesDeSecours }
                POST /auth/2fa/desactiver { password, codeTotp }
      DECISION  on appelle les routes reelles. Regle generale : une adresse
                se recopie depuis /api/docs, jamais de memoire.

  E12. LA SESSION SERIALISEE DANS localStorage (dayoch_session_v1)
      Constat   l utilisateur, ses roles et ses permissions sont gardes dans
                le navigateur entre deux visites.
      Risque    des droits stockes localement peuvent etre perimes (role
                retire hier) ou modifies a la main. L ecran afficherait alors
                des actions que le serveur refusera.
      DECISION  seul le jeton de rafraichissement est persiste
                (dayopi.refreshToken), plus la filiale de travail
                (dayopi.filialeCourante). Au demarrage, la session est
                reprise par /auth/refresh puis /auth/profil : les droits
                affiches sont toujours ceux du serveur, a l instant present.

I.3  LANGAGE : TYPESCRIPT
  Le projet du stagiaire est en JavaScript (.jsx/.js). Le front de reference
  est en TypeScript strict. DECISION : TypeScript.
  Raison concrete, pas de principe : les douze ecarts ci-dessus sont presque
  tous des desaccords de FORME entre le front et le backend (noms de route,
  noms de permission, forme d un profil). Un fichier types.ts qui recopie le
  contrat transforme ces desaccords en erreurs de compilation, signalees
  avant meme d ouvrir le navigateur.

I.4  LA BASE DE CODE
  Le stagiaire ne repart PAS de zero. La pile est identique (React 19,
  Vite 8, Tailwind 4, React Router 7, Motion, ReactFlow, lucide, Axios,
  TanStack Query). La base est le front de reference ; le stagiaire y porte
  son travail d interface ecran par ecran, en suivant la partie III. Ce
  qui a de la valeur dans son projet (mise en page, composants visuels,
  parcours) est conserve ; ce qui contredit le backend est remplace.


================================================================================
PARTIE II - REGLES NON NEGOCIABLES
================================================================================

  R1  Le backend est la seule source de verite : routes, roles,
      permissions, menus, indicateurs, regles metier.
  R2  Aucune donnee simulee dans le code livre. Aucune variable de
      contournement de l authentification.
  R3  Aucun secret dans le navigateur au-dela du jeton de rafraichissement :
      ni mot de passe, ni secret TOTP, ni code de secours, ni lien de
      reinitialisation apres fermeture de l ecran qui l affiche.
  R4  Une URL ne s ecrit que dans un fichier api.ts. Axios ne s importe que
      dans shared/api/client.ts.
  R5  Une cle de cache ne s ecrit que dans un fichier hooks.ts, et contient
      tout ce qui change la reponse, perimetre compris.
  R6  Le cache est vide a chaque connexion et deconnexion (deja en place
      dans contexte-auth.tsx : sans cela, sur un poste partage, le compte
      suivant voyait d abord les donnees du precedent).
  R7  shared/ ne connait aucun domaine metier. app/ assemble. Un domaine
      peut importer le domaine agents (referentiel central), jamais
      l inverse.
  R8  Chaque ecran : etats chargement, erreur, vide. Message d erreur du
      serveur affiche tel quel (il est en francais).
  R9  `npm run lint` et `npm run build` passent, console du navigateur vide,
      avant toute demande de fusion.
  R10 Un module dont le backend n expose pas les routes n a pas d ecran.

    // Decoupage explicite : les grosses dependances changent rarement, elles
    // restent donc en cache navigateur quand notre code evolue.

    // laisser l outil decider.

        manualChunks(identifiant) {

          if (/node_modules\/(react|react-dom|react-router)/.test(identifiant)) {
            return 'react-vendor';
          }
          return undefined;
        },
      },
    },
  },

import { QueryClient } from '@tanstack/react-query';

import { ErreurApi } from '@/shared/api/erreurs';

/**
 * Cache des donnees du serveur.
 *
 * Pourquoi cette dependance alors que la pile annoncee ne mentionnait
 * qu Axios ? Parce que les deux ne font pas le meme travail et ne se
 * remplacent pas :
 *
 *   Axios          TRANSPORTE la requete (en-tetes, jetons, erreurs)
 *   React Query    MEMORISE la reponse (cache, invalidation, etats)
 *
 * Sans cache, chaque ecran reecrit a la main le meme useEffect, avec les
 * memes quatre defauts : pas de gestion d erreur, rechargement a chaque
 * visite, conditions de course quand les filtres changent vite, et requetes
 * non annulees au demontage. C est le levier de proprete le plus rentable du
 * projet ; le retirer ferait grossir chaque page de trente lignes.
 */
export const creerQueryClient = (): QueryClient =>
  new QueryClient({
    defaultOptions: {
      queries: {
        staleTime: 30_000,
        refetchOnWindowFocus: false,
        retry: (nombreEchecs, erreur) => {
          // Inutile de rejouer une erreur de droits ou de saisie : la reponse
          // sera la meme. On ne reessaie que les pannes passageres.
          if (erreur instanceof ErreurApi && erreur.statut > 0 && erreur.statut < 500) return false;
          return nombreEchecs < 2;
        },
      },
      mutations: { retry: false }, // une ecriture rejouee peut creer un doublon
    },
  });

import { useQueryClient } from '@tanstack/react-query';
import { useEffect } from 'react';

import { useFiliales } from '@/fonctionnalites/organisation/filiales/hooks';
import { useAuth } from '@/shared/auth/useAuth';
import { Champ } from '@/shared/ui/Champ';

/**
 * Filiale de travail des comptes de niveau groupe.
 *
 * Un SuperAdmin n est rattache a aucune filiale : sans ce choix, le serveur
 * ne sait pas sur quel perimetre repondre. Pour un utilisateur de filiale, le
 * composant ne s affiche pas : son perimetre est impose par le backend, et
 * aucun reglage du navigateur ne peut le changer.
 *
 * Changer de filiale ne vide pas le cache : le perimetre fait partie des cles
 * (voir usePerimetre). Les deux filiales gardent chacune leurs donnees.
 */
export function SelecteurFiliale() {
  const { estCompteGroupe, filialeCourante, changerFiliale } = useAuth();
  const queryClient = useQueryClient();

  const filiales = useFiliales(estCompteGroupe);

  const premiere = filiales.data?.items[0];

  useEffect(() => {
    if (estCompteGroupe && !filialeCourante && premiere) changerFiliale(premiere.id);
  }, [estCompteGroupe, filialeCourante, premiere, changerFiliale]);

  if (!estCompteGroupe) return null;

  return (
    <Champ libelle="Filiale de travail">
      <select
        value={filialeCourante ?? ''}
        onChange={(evenement) => {
          changerFiliale(evenement.target.value || null);
          // Les requetes deja en cache portent l ancien perimetre dans leur
          // cle ; celles en vol, non. On les relance.
          void queryClient.invalidateQueries();
        }}
      >
        {filiales.data?.items.map((filiale) => (
          <option key={filiale.id} value={filiale.id}>
            {filiale.code} - {filiale.nom}
          </option>
        ))}
      </select>
    </Champ>
  );
}

import axios from 'axios';

import type { CorpsErreurApi } from './types-api';

/**
 * Erreur applicative normalisee.
 *
 * Une erreur n est pas une chaine : c est un statut, un code, un message deja
 * traduit et, pour une erreur de validation, le detail champ par champ. En
 * faire une classe permet de l attraper precisement et de decider quoi
 * afficher plutot que de tout montrer de la meme facon.
 */
export class ErreurApi extends Error {
  readonly statut: number;
  readonly code: string;
  readonly details: string[];

  constructor(statut: number, message: string, code = 'ERREUR', details: string[] = []) {
    super(message);
    this.name = 'ErreurApi';
    this.statut = statut;
    this.code = code;
    this.details = details;
  }

  get estSessionExpiree(): boolean {
    return this.statut === 401;
  }

  get estDroitsInsuffisants(): boolean {
    return this.statut === 403;
  }

  get estSaisieInvalide(): boolean {
    return this.statut === 400 || this.statut === 422;
  }
}

const MESSAGES: Record<number, string> = {
  400: 'Donnees invalides.',
  401: 'Session expiree, reconnectez-vous.',
  403: "Vous n avez pas les droits pour cette action.",
  404: 'Element introuvable.',
  409: "Conflit : cette operation est impossible en l etat.",
  413: 'Fichier trop volumineux.',
  429: 'Trop de requetes, patientez un instant.',
  500: 'Erreur du serveur. Reessayez dans un moment.',
  503: 'Service momentanement indisponible.',
};

/**
 * Traduit n importe quoi en ErreurApi.
 *
 * Axios rejette sur les statuts d erreur, contrairement a fetch : le code
 * d appel n a donc plus a tester reponse.ok. En revanche il faut distinguer
 * trois cas qu Axios melange : reponse d erreur du serveur, requete partie
 * sans reponse (reseau coupe), et erreur de programmation.
 */
export function normaliserErreur(echec: unknown): ErreurApi {
  if (echec instanceof ErreurApi) return echec;

  if (axios.isCancel(echec)) {
    return new ErreurApi(0, 'Requete annulee.', 'ANNULEE');
  }

  if (axios.isAxiosError<CorpsErreurApi>(echec)) {
    const reponse = echec.response;

    if (!reponse) {
      return new ErreurApi(0, 'Serveur injoignable. Verifiez votre connexion.', 'RESEAU');
    }

    const corps = reponse.data;
    const details = Array.isArray(corps?.message) ? corps.message : [];
    const message =
      details[0] ??
      (typeof corps?.message === 'string' ? corps.message : undefined) ??
      MESSAGES[reponse.status] ??
      `Erreur inattendue (${reponse.status}).`;

    return new ErreurApi(reponse.status, message, corps?.code ?? 'ERREUR', details);
  }

  return new ErreurApi(0, echec instanceof Error ? echec.message : 'Erreur inconnue.');
}

/** Message affichable, quelle que soit la nature de ce qui a ete attrape. */
export const messageLisible = (echec: unknown): string => normaliserErreur(echec).message;

const CLE_REFRESH = 'dayopi.refreshToken';
const CLE_FILIALE = 'dayopi.filialeCourante';

/**
 * Conservation des jetons.
 *
 * Le jeton d acces reste en MEMOIRE : il disparait a la fermeture de
 * l onglet, et un script injecte dans la page ne peut pas le lire dans
 * localStorage. Le jeton de rafraichissement, lui, doit survivre au
 * rechargement : il va donc dans localStorage.
 *
 * Ce n est pas l ideal theorique. La meilleure solution reste un cookie
 * httpOnly, que JavaScript ne peut pas lire du tout ; elle demande une
 * adaptation du backend (cookies + protection CSRF). Le compromis est ecrit
 * ici, a l endroit ou il est pris : un compromis documente est une decision,
 * un compromis tacite est une dette.
 */
let jetonAcces: string | null = null;

const lire = (cle: string): string | null => {
  try {
    return localStorage.getItem(cle);
  } catch {
    // Navigation privee ou stockage desactive : on fonctionne sans persistance.
    return null;
  }
};

const ecrire = (cle: string, valeur: string | null): void => {
  try {
    if (valeur === null) localStorage.removeItem(cle);
    else localStorage.setItem(cle, valeur);
  } catch {
    /* sans persistance, la session durera le temps de l onglet */
  }
};

export const jetons = {
  acces: (): string | null => jetonAcces,
  rafraichissement: (): string | null => lire(CLE_REFRESH),

  enregistrer(acces: string, rafraichissement: string): void {
    jetonAcces = acces;
    ecrire(CLE_REFRESH, rafraichissement);
  },

  majAcces(acces: string): void {
    jetonAcces = acces;
  },

  effacer(): void {
    jetonAcces = null;
    ecrire(CLE_REFRESH, null);
  },

  /** Filiale de travail d un compte de niveau groupe. */
  filiale: (): string | null => lire(CLE_FILIALE),
  definirFiliale: (id: string | null): void => ecrire(CLE_FILIALE, id),
};

 * C est tout l interet de l instance Axios : ni les composants ni les
 * fonctions d API ne s occupent de l authentification. Une seule ligne a
 * changer le jour ou le backend passera aux cookies.
 */
client.interceptors.request.use((config) => {
  const acces = jetons.acces();
  if (acces) config.headers.Authorization = `Bearer ${acces}`;

  const filiale = jetons.filiale();
  if (filiale) config.headers['X-Filiale-Id'] = filiale;

  return config;
});

// ---------------------------------------------------------------- reponses

/**
 * Rafraichissement du jeton, une seule fois a la fois.
 *
 * Le probleme a connaitre : cinq requetes partent en parallele, les cinq
 * recoivent 401, et cinq rafraichissements partent. Comme le backend fait
 * TOURNER les jetons de rafraichissement, le deuxieme presente un jeton deja
 * consomme ; le serveur en deduit un vol et revoque toutes les sessions.
 * L utilisateur est deconnecte sans comprendre pourquoi.
 *
 * La parade tient en une variable : la promesse en cours est partagee, les
 * autres requetes l attendent au lieu d en lancer une nouvelle.
 */
let rafraichissementEnCours: Promise<boolean> | null = null;

async function rafraichir(): Promise<boolean> {
  const refresh = jetons.rafraichissement();
  if (!refresh) return false;

  rafraichissementEnCours ??= (async () => {
    try {
      // Appel direct avec axios, et non avec `client` : l intercepteur de
      // reponse ne doit pas intercepter son propre rafraichissement.
      const { data } = await axios.post<{ accessToken: string; refreshToken: string }>(
        `${import.meta.env.VITE_API_URL ?? '/api/v1'}/auth/refresh`,
        { refreshToken: refresh },
      );
      jetons.enregistrer(data.accessToken, data.refreshToken);
      return true;
    } catch {
      return false;
    } finally {
      rafraichissementEnCours = null;
    }
  })();

  return rafraichissementEnCours;
}

/** Echange volontaire au demarrage : evite un 401 garanti au premier appel. */
export const reprendreSession = (): Promise<boolean> => rafraichir();

client.interceptors.response.use(
  (reponse) => reponse,
  async (echec: unknown) => {
    if (!axios.isAxiosError(echec) || !echec.config) {
      throw normaliserErreur(echec);
    }

    const config = echec.config as ConfigInterne;
    const statut = echec.response?.status;

    if (statut === 401 && !config._rejoue) {
      config._rejoue = true; // une seule tentative, jamais de boucle

      if (await rafraichir()) {
        return client.request(config);
      }

      jetons.effacer();
      abonnes.forEach((abonne) => abonne());
      throw new ErreurApi(401, 'Session expiree, reconnectez-vous.', 'SESSION_EXPIREE');
    }

    throw normaliserErreur(echec);
  },
);

/**
 * Retire les valeurs vides avant d envoyer les parametres.
 *
 * Un formulaire de filtres envoie volontiers "?dateDebut=&serviceId=". Le
 * backend refuse ces chaines vides avec un 400, et il a raison de le faire :
 * c est au client de ne pas envoyer un filtre qu il ne filtre pas.
 */
export function nettoyerParametres(parametres: Record<string, unknown> = {}): Record<string, unknown> {
  const propres: Record<string, unknown> = {};

  for (const [cle, valeur] of Object.entries(parametres)) {
    if (valeur === undefined || valeur === null || valeur === '') continue;
    if (Array.isArray(valeur)) {
      if (valeur.length) propres[cle] = valeur.join(',');
      continue;
    }
    propres[cle] = valeur;
  }
  return propres;
}

/** Lecture typee, avec nettoyage des parametres. */
export async function lire<T>(
  chemin: string,
  parametres?: Record<string, unknown>,
  config?: AxiosRequestConfig,
): Promise<T> {
  const { data } = await client.get<T>(chemin, {
    ...config,
    params: nettoyerParametres(parametres),
  });
  return data;
}

/**
 * Telechargement d un fichier protege par le jeton.
 *
 * Une balise <a href> ne conviendrait pas : le navigateur n y mettrait pas
 * l en-tete Authorization. On recupere donc le binaire, on cree une URL
 * temporaire, on declenche le clic, puis on LIBERE l URL — sans cette
 * derniere etape, le fichier reste en memoire jusqu au rechargement.
 */
export async function telecharger(
  chemin: string,
  parametres: Record<string, unknown> = {},
): Promise<void> {
  const reponse = await client.get<Blob>(chemin, {
    params: nettoyerParametres(parametres),
    responseType: 'blob',
  });

  const url = URL.createObjectURL(reponse.data);
  const lien = document.createElement('a');

  lien.href = url;
  lien.download =
    nomFichierDepuisEnTete(reponse.headers['content-disposition'] as string | undefined) ?? 'export';
  document.body.appendChild(lien);
  lien.click();
  lien.remove();
  URL.revokeObjectURL(url);
}

/** Content-Disposition: attachment; filename="agents_BEN.xlsx" -> agents_BEN.xlsx */
export function nomFichierDepuisEnTete(enTete: string | undefined): string | null {
  if (!enTete) return null;
  const correspondance = /filename\*?=(?:UTF-8'')?"?([^";]+)"?/i.exec(enTete);
  return correspondance?.[1] ? decodeURIComponent(correspondance[1]) : null;
}

/** Image servie par une route protegee : rendue sous forme d URL temporaire. */
export async function chargerImage(chemin: string): Promise<string> {
  const reponse = await client.get<Blob>(chemin, { responseType: 'blob' });
  return URL.createObjectURL(reponse.data);
}

/**
 * Televersement.
 *
 * Ne JAMAIS poser Content-Type soi-meme sur un FormData : le navigateur doit
 * composer l en-tete lui-meme pour y inclure la frontiere ("boundary") qui
 * separe les parties. L ecrire a la main casse l envoi de facon difficile a
 * diagnostiquer.
 */
export async function televerser(chemin: string, fichier: File): Promise<void> {
  const formulaire = new FormData();
  formulaire.append('fichier', fichier);
  await client.post(chemin, formulaire);
}

import { useQueryClient } from '@tanstack/react-query';
import { useCallback, useEffect, useMemo, useState, type ReactNode } from 'react';

import { reprendreSession, surSessionPerdue } from '@/shared/api/client';
import { jetons } from '@/shared/api/jetons';

import { apiAuth } from './api-auth';
import { ContexteAuth, type ValeurAuth } from './contexte';
import { estDefiDeuxFacteurs, ROLES, type UtilisateurConnecte } from './types';

/**
 * Session de l utilisateur.
 *
 * Le contexte est reserve a ce qui est vraiment global : la session et le
 * perimetre de travail. Tout y mettre ferait rerendre l application entiere
 * au moindre changement.
 */
export function FournisseurAuth({ children }: { children: ReactNode }) {
  const [utilisateur, setUtilisateur] = useState<UtilisateurConnecte | null>(null);

  /**
   * Le cache des donnees appartient a UNE session.
   *
   * Sans ce nettoyage, sur un poste partage, le compte suivant se voyait
   * d abord servir le menu, les listes et les fiches gardes en memoire pour
   * le precedent, le temps qu ils soient rafraichis. Le cache est donc vide a
   * chaque ouverture et a chaque fermeture de session.
   */
  const queryClient = useQueryClient();

  // L etat initial est CALCULE, pas corrige ensuite : sans jeton de
  // rafraichissement il n y a rien a reprendre, donc rien a attendre.
  // Partir de `true` puis repasser a `false` dans un effet provoquerait un
  // rendu supplementaire — et surtout un bref ecran de chargement a chaque
  // ouverture de l application par un visiteur non connecte.
  const [chargement, setChargement] = useState(() => Boolean(jetons.rafraichissement()));
  const [filiale, setFiliale] = useState<string | null>(() => jetons.filiale());

  const changerFiliale = useCallback((filialeId: string | null) => {
    setFiliale(filialeId);
    jetons.definirFiliale(filialeId);
  }, []);

  /*
   * Reprise de session au demarrage.
   *
   * Ordre important : on echange d abord le jeton de rafraichissement contre
   * un jeton d acces, PUIS on demande le profil. L ordre inverse fonctionne
   * aussi, au prix d un 401 systematique a chaque chargement de page — une
   * erreur attendue reste une erreur, et elle finit par masquer les vraies.
   */
  useEffect(() => {
    if (!jetons.rafraichissement()) return;

    let actif = true;

    void (async () => {
      try {
        if (!(await reprendreSession())) throw new Error('Session non reprise.');
        const profil = await apiAuth.profil();
        if (actif) setUtilisateur(profil);
      } catch {
        jetons.effacer();
      } finally {
        if (actif) setChargement(false);
      }
    })();

    // Nettoyage : si le composant disparait avant la reponse, on ne touche
    // plus a son etat.
    return () => {
      actif = false;
    };
  }, []);

  // Le client Axios previent quand la session est definitivement perdue.
  useEffect(
    () =>
      surSessionPerdue(() => {
        queryClient.clear();
        setUtilisateur(null);
      }),
    [queryClient],
  );

  const connecter = useCallback(
    async (identifiant: string, password: string, codeTotp?: string) => {
      const resultat = await apiAuth.connexion(identifiant, password, codeTotp);

      if (!estDefiDeuxFacteurs(resultat)) {
        queryClient.clear();
        jetons.enregistrer(resultat.accessToken, resultat.refreshToken);
        setUtilisateur(resultat.utilisateur);
      }
      return resultat;
    },
    [queryClient],
  );

  const terminerConnexion2fa = useCallback(async (challengeToken: string, codeTotp: string) => {
    const resultat = await apiAuth.verifier2fa(challengeToken, codeTotp);
    queryClient.clear();
    jetons.enregistrer(resultat.accessToken, resultat.refreshToken);
    setUtilisateur(resultat.utilisateur);
  }, [queryClient]);

  const deconnecter = useCallback(async () => {
    const refresh = jetons.rafraichissement();
    try {
      if (refresh) await apiAuth.deconnexion(refresh);
    } finally {
      // Meme si l appel echoue, la session locale se ferme : l utilisateur a
      // demande a partir, le reseau ne doit pas l en empecher.
      jetons.effacer();
      // La filiale de travail aussi : c est un choix du compte qui part, pas
      // un reglage du poste.
      jetons.definirFiliale(null);
      setFiliale(null);
      queryClient.clear();
      setUtilisateur(null);
    }
  }, [queryClient]);

  const peut = useCallback(
    (permission: string) =>
      Boolean(
        utilisateur &&
          (utilisateur.roles.includes(ROLES.SUPER_ADMIN) ||
            utilisateur.permissions.includes(permission)),
      ),
    [utilisateur],
  );

  const aRole = useCallback(
    (...roles: string[]) => Boolean(utilisateur && roles.some((r) => utilisateur.roles.includes(r))),
    [utilisateur],
  );

  // useMemo : sans lui, l objet serait recree a chaque rendu et tous les
  // composants abonnes au contexte se rerendraient pour rien.
  const valeur = useMemo<ValeurAuth>(
    () => ({
      utilisateur,
      chargement,
      filialeCourante: filiale,
      estCompteGroupe: utilisateur?.filialeId === null,
      connecter,
      terminerConnexion2fa,
      deconnecter,
      changerFiliale,
      peut,
      aRole,
    }),
    [utilisateur, chargement, filiale, connecter, terminerConnexion2fa, deconnecter, changerFiliale, peut, aRole],
  );

  return <ContexteAuth.Provider value={valeur}>{children}</ContexteAuth.Provider>;
}

import { useEffect, useState } from 'react';

/**
 * Retarde la propagation d une valeur.
 *
 * Sans cela, taper "kponou" lance six requetes, une par lettre, et les
 * reponses peuvent revenir dans le desordre : le resultat de "kpon"
 * s afficherait apres celui de "kponou".
 *
 * Le `return` de useEffect annule le minuteur precedent : c est lui qui fait
 * tout le travail. Sans ce nettoyage, les minuteurs s accumulent.
 */
export function useDebounce<T>(valeur: T, delaiMs = 350): T {
  const [valeurRetardee, setValeurRetardee] = useState(valeur);

  useEffect(() => {
    const minuteur = setTimeout(() => setValeurRetardee(valeur), delaiMs);
    return () => clearTimeout(minuteur);
  }, [valeur, delaiMs]);

  return valeurRetardee;
}

import { useCallback, useMemo } from 'react';
import { useSearchParams } from 'react-router-dom';

export type Filtres = Record<string, string>;

/**
 * Les filtres vivent dans l URL, pas dans un useState.
 *
 * Trois consequences concretes :
 *  - la page filtree se partage par copier-coller du lien ;
 *  - le bouton Precedent revient au filtre precedent ;
 *  - un rechargement conserve la recherche en cours.
 *
 * L URL devient la source de verite, React n en est que le reflet.
 */
export function useFiltresUrl(valeursParDefaut: Filtres = {}) {
  const [parametres, setParametres] = useSearchParams();

  // La dependance porte sur la CHAINE : l objet URLSearchParams change
  // d identite a chaque rendu, pas son contenu. On extrait la chaine ici,
  // car une liste de dependances n accepte que des expressions simples.
  const chaineParametres = parametres.toString();

  const filtres = useMemo<Filtres>(() => {
    const resultat: Filtres = { ...valeursParDefaut };
    parametres.forEach((valeur, cle) => {
      resultat[cle] = valeur;
    });
    return resultat;
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [chaineParametres]);

  /** Modifie un filtre et revient page 1 : sinon on reste sur une page vide. */
  const definir = useCallback(
    (cle: string, valeur: string | null) => {
      const suivants = new URLSearchParams(parametres);

      if (valeur === null || valeur === '') suivants.delete(cle);
      else suivants.set(cle, valeur);

      if (cle !== 'page') suivants.delete('page');
      setParametres(suivants, { replace: true });
    },
    [parametres, setParametres],
  );

  const reinitialiser = useCallback(() => setParametres(new URLSearchParams()), [setParametres]);

  return { filtres, definir, reinitialiser };
}

/** 70 -> "5 ans et 10 mois" : plus parlant qu un nombre de mois brut. */
export function formaterDuree(mois: number): string {
  if (mois < 1) return 'moins d un mois';
  const annees = Math.floor(mois / 12);
  const reste = mois % 12;

  const morceaux: string[] = [];
  if (annees) morceaux.push(`${annees} an${annees > 1 ? 's' : ''}`);
  if (reste) morceaux.push(`${reste} mois`);
  return morceaux.join(' et ');
}

import {
  Children,
  cloneElement,
  isValidElement,
  useId,
  type InputHTMLAttributes,
  type ReactElement,
  type ReactNode,
} from 'react';

import { cn } from '@/shared/utils/cn';

interface Props extends Omit<InputHTMLAttributes<HTMLInputElement>, 'id' | 'children'> {
  libelle: string;
  aide?: string;
  erreur?: string;
  /** Remplace l input par un select, une case a cocher, etc. */
  children?: ReactNode;
}

const STYLE_CONTROLE =
  'h-10 w-full rounded-md border border-filet bg-white px-3 text-sm text-encre placeholder:text-encre-douce/60';

/**
 * Champ de formulaire accessible.
 *
 * useId genere un identifiant stable qui relie <label> et controle. Point a
 * ne pas rater : quand le controle arrive en children (un <select>), il faut
 * lui TRANSMETTRE cet identifiant, sinon le label designe un element qui
 * n existe pas. Cliquer sur le libelle ne fait rien, et un lecteur d ecran
 * annonce un controle sans nom.
 */
export function Champ({ libelle, aide, erreur, children, className, ...reste }: Props) {
  const id = useId();
  const idAide = `${id}-aide`;
  const idErreur = `${id}-erreur`;
  const decrivants = [aide ? idAide : null, erreur ? idErreur : null].filter(Boolean).join(' ');

  const controle = (() => {
    if (!children) return null;

    const enfant = Children.only(children) as ReactElement<Record<string, unknown>>;
    if (!isValidElement(enfant)) return children;

    return cloneElement(enfant, {
      id: (enfant.props.id as string | undefined) ?? id,
      'aria-invalid': erreur ? true : undefined,
      'aria-describedby': decrivants || undefined,
      className: cn(STYLE_CONTROLE, enfant.props.className as string | undefined),
    });
  })();

  return (
    <div className="flex flex-col gap-1">
      <label htmlFor={id} className="text-xs font-semibold text-encre-douce">
        {libelle}
      </label>

      {controle ?? (
        <input
          id={id}
          aria-invalid={erreur ? true : undefined}
          aria-describedby={decrivants || undefined}
          className={cn(STYLE_CONTROLE, erreur && 'border-dayo-rouge', className)}
          {...reste}
        />
      )}

      {aide && (
        <span id={idAide} className="text-xs text-encre-douce">
          {aide}
        </span>
      )}
      {erreur && (
        <span id={idErreur} role="alert" className="text-xs text-dayo-rouge">
          {erreur}
        </span>
      )}
    </div>
  );
}

import { motion, useReducedMotion } from 'motion/react';
import type { ReactNode } from 'react';

/**
 * Transition d entree d une page.
 *
 * useReducedMotion lit le reglage systeme "reduire les animations". Quand il
 * est actif, on ne desactive pas seulement l animation : on rend le contenu
 * immediatement a sa position finale. Une animation ignoree qui laisse le
 * contenu invisible serait pire que pas d animation du tout.
 *
 * Les durees restent courtes (0,18 s). Au-dela, l animation ne decore plus :
 * elle fait attendre.
 */
export function TransitionPage({ children }: { children: ReactNode }) {
  const mouvementReduit = useReducedMotion();

  if (mouvementReduit) return <>{children}</>;

  return (
    <motion.div
      initial={{ opacity: 0, y: 8 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ duration: 0.18, ease: 'easeOut' }}
    >
      {children}
    </motion.div>
  );
}

/**
 * Apparition en cascade d une liste de cartes.
 *
 * `delay` croit avec l index, mais il est PLAFONNE : sans ce plafond, la
 * centieme carte d une grille attendrait deux secondes avant d apparaitre.
 */
export function AnimationCarte({ index, children }: { index: number; children: ReactNode }) {
  const mouvementReduit = useReducedMotion();

  if (mouvementReduit) return <>{children}</>;

  return (
    <motion.div
      initial={{ opacity: 0, y: 10 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ duration: 0.2, delay: Math.min(index * 0.02, 0.3), ease: 'easeOut' }}
    >
      {children}
    </motion.div>
  );
}

/**
 * Le composant ne sait pas CE QU il exporte : il recoit une fonction. Il sert
 * donc pour les agents, la carriere, le trombinoscope et l organigramme sans
 * une ligne de plus. C est l inversion de dependance, version React.
 */
export function BoutonsExport({
  onExport,
  formats = ['xlsx', 'pdf', 'csv'],
}: {
  onExport: (format: FormatExport) => Promise<void>;
  formats?: FormatExport[];
}) {

    setErreur(null);
    try {
      await onExport(format);
    } catch (echec) {
      setErreur(messageLisible(echec));
    } finally {
      setEnCours(null);
    }
  }

  return (
    <div className="flex flex-col gap-2">
      <div className="flex flex-wrap gap-2">
        {formats.map((format) => (
          <Bouton
            key={format}
            variante="secondaire"
            taille="sm"

            disabled={enCours !== null}
            onClick={() => void exporter(format)}
            icone={<Download className="size-4" aria-hidden="true" />}

            {LIBELLES[format]}

import { LogIn, ShieldCheck } from 'lucide-react';
import { useState, type FormEvent } from 'react';
import { Navigate, useLocation, useNavigate } from 'react-router-dom';

import { messageLisible } from '@/shared/api/erreurs';
import { estDefiDeuxFacteurs } from '@/shared/auth/types';
import { useAuth } from '@/shared/auth/useAuth';
import { Bouton } from '@/shared/ui/Bouton';
import { Champ } from '@/shared/ui/Champ';
import { MessageErreur } from '@/shared/ui/Etats';
import { NOM_APPLICATION } from '@/app/application';

/**
 * Connexion, en deux temps : identifiants, puis code a six chiffres si le
 * compte a la double authentification.
 *
 * L etat local suffit : rien de ce qui est tape ici n a de raison de vivre
 * ailleurs que dans cette page.
 */
export function PageConnexion() {
  const { utilisateur, connecter, terminerConnexion2fa } = useAuth();
  const naviguer = useNavigate();
  const emplacement = useLocation();

  const [identifiant, setIdentifiant] = useState('');
  const [motDePasse, setMotDePasse] = useState('');
  const [code, setCode] = useState('');
  const [defi, setDefi] = useState<string | null>(null);
  const [erreur, setErreur] = useState<string | null>(null);
  const [envoi, setEnvoi] = useState(false);

  if (utilisateur) return <Navigate to="/tableau-de-bord" replace />;

  const destination = (emplacement.state as { depuis?: string } | null)?.depuis ?? '/tableau-de-bord';

  async function soumettre(evenement: FormEvent) {
    // Sans ceci, le navigateur recharge la page et React perd tout son etat.
    evenement.preventDefault();
    setErreur(null);
    setEnvoi(true);

    try {
      if (defi) {
        await terminerConnexion2fa(defi, code);
      } else {
        const resultat = await connecter(identifiant.trim(), motDePasse);
        if (estDefiDeuxFacteurs(resultat)) {
          setDefi(resultat.challengeToken);
          return; // on attend le code, on ne navigue pas encore
        }
      }
      naviguer(destination, { replace: true });
    } catch (echec) {
      setErreur(messageLisible(echec));
    } finally {
      // Le bouton se reactive meme en cas d echec : sinon l utilisateur reste
      // devant un formulaire bloque.
      setEnvoi(false);
    }
  }

  return (
    <main className="grid min-h-screen place-items-center bg-fond p-6">
      <form onSubmit={soumettre} noValidate className="carte flex w-full max-w-md flex-col gap-4 p-6">
        <div>
          <p className="font-bold text-dayo-bleu">
            {NOM_APPLICATION}
          </p>
          <h1 className="text-xl font-bold">{defi ? 'Verification' : 'Connexion'}</h1>
        </div>

        {erreur && <MessageErreur>{erreur}</MessageErreur>}

        {defi ? (
          <Champ
            libelle="Code de verification"
            aide="Les six chiffres affiches par Google Authenticator."
            value={code}
            onChange={(e) => setCode(e.target.value)}
            inputMode="numeric"
            autoComplete="one-time-code"
            maxLength={6}
            required
            autoFocus
          />
        ) : (
          <>
            <Champ
              libelle="Matricule ou email"
              aide="Les agents sans adresse email se connectent avec leur matricule."
              value={identifiant}
              onChange={(e) => setIdentifiant(e.target.value)}
              autoComplete="username"
              required
              autoFocus
            />
            <Champ
              libelle="Mot de passe"
              type="password"
              value={motDePasse}
              onChange={(e) => setMotDePasse(e.target.value)}
              autoComplete="current-password"
              required
            />
          </>
        )}

        <Bouton
          type="submit"
          chargement={envoi}
          icone={
            defi ? (
              <ShieldCheck className="size-4" aria-hidden="true" />
            ) : (
              <LogIn className="size-4" aria-hidden="true" />
            )
          }
        >
          {defi ? 'Valider le code' : 'Se connecter'}
        </Bouton>
      </form>
    </main>
  );
}

/**
 * Apres une ecriture, on INVALIDE plutot que de modifier le cache a la main :
 * le serveur reste la source de verite, et il calcule des champs que le front
 * ne sait pas deviner (duree, statut, references).
 */
export function useInvalidationAgent(id: string) {
  const queryClient = useQueryClient();
  const perimetre = usePerimetre();

  return () =>

      queryClient.invalidateQueries({ queryKey: clesAgents.historique(perimetre, id) }),
      queryClient.invalidateQueries({ queryKey: clesAgents.listes(perimetre) }),
    ]);
}

  const champFichier = useRef<HTMLInputElement>(null);
  const traceEnCours = useRef(false);

  const [vide, setVide] = useState(true);
  const [envoiFichier, setEnvoiFichier] = useState(false);
  const [erreur, setErreur] = useState<string | null>(null);

  const mutation = useSignatureTracee(agentId);
  const invalider = useInvalidationAgent(agentId);

  useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas) return;

    const densite = window.devicePixelRatio || 1;
    canvas.width = LARGEUR * densite;
    canvas.height = HAUTEUR * densite;

    const contexte = canvas.getContext('2d');
    if (!contexte) return;

    contexte.scale(densite, densite);
    contexte.lineWidth = 2.5;
    contexte.lineCap = 'round';
    contexte.lineJoin = 'round';
    contexte.strokeStyle = '#1f2933';
  }, []);

  const position = (evenement: PointerEvent<HTMLCanvasElement>) => {
    const rectangle = evenement.currentTarget.getBoundingClientRect();
    // Coordonnees ecran ramenees dans le repere du canvas, en tenant compte
    // d un eventuel redimensionnement CSS.
    return {
      x: ((evenement.clientX - rectangle.left) / rectangle.width) * LARGEUR,
      y: ((evenement.clientY - rectangle.top) / rectangle.height) * HAUTEUR,
    };
  };

  const commencer = (evenement: PointerEvent<HTMLCanvasElement>) => {
    const contexte = canvasRef.current?.getContext('2d');
    if (!contexte) return;

    evenement.currentTarget.setPointerCapture(evenement.pointerId);
    const { x, y } = position(evenement);

    contexte.beginPath();
    contexte.moveTo(x, y);
    traceEnCours.current = true;
    setVide(false);
  };

  const tracer = (evenement: PointerEvent<HTMLCanvasElement>) => {
    if (!traceEnCours.current) return;
    const contexte = canvasRef.current?.getContext('2d');
    if (!contexte) return;

    const { x, y } = position(evenement);
    contexte.lineTo(x, y);
    contexte.stroke();
  };

  const effacer = useCallback(() => {
    const canvas = canvasRef.current;
    const contexte = canvas?.getContext('2d');
    if (!canvas || !contexte) return;

    contexte.clearRect(0, 0, canvas.width, canvas.height);
    setVide(true);
  }, []);

  async function enregistrerTrace() {
    const canvas = canvasRef.current;
    if (!canvas || vide) return;

    setErreur(null);
    try {
      // PNG : il conserve la transparence, ce qui permettra de poser la
      // signature sur un document sans rectangle blanc autour.
      await mutation.mutateAsync(canvas.toDataURL('image/png'));
      surEnregistrement?.();
    } catch (echec) {
      setErreur(messageLisible(echec));
    }
  }

  async function chargerImage(evenement: ChangeEvent<HTMLInputElement>) {
    const fichier = evenement.target.files?.[0];
    if (!fichier) return;

    setErreur(null);

    // Verification cote client AUSSI : non par confiance — un utilisateur
    // peut contourner tout ce qui tourne dans son navigateur — mais pour
    // eviter d envoyer un fichier trop lourd avant d apprendre qu il est
    // refuse. Le controle qui compte reste celui du serveur, qui reconnait
    // le type sur les premiers octets et non sur l extension.
    if (!TYPES_ACCEPTES.includes(fichier.type)) {
      setErreur('Formats acceptes : PNG, JPEG ou WebP.');
      return;
    }
    if (fichier.size > TAILLE_MAX_OCTETS) {
      setErreur(`Image trop lourde (${Math.round(fichier.size / 1024)} Kio pour 1024 Kio maximum).`);
      return;
    }

    setEnvoiFichier(true);
    try {
      await apiAgents.envoyerSignatureFichier(agentId, fichier);
      await invalider();
      surEnregistrement?.();
    } catch (echec) {
      setErreur(messageLisible(echec));
    } finally {
      setEnvoiFichier(false);
      // Remettre le champ a zero permet de reselectionner LE MEME fichier
      // apres une correction : sinon l evenement change ne part pas.
      if (champFichier.current) champFichier.current.value = '';
    }
  }

  return (
    <div className="flex flex-col gap-3">
      <p className="text-sm text-encre-douce">
        Tracez la signature ci-dessous, ou chargez une image deja numerisee.
      </p>

      <canvas
        ref={canvasRef}
        style={{ width: LARGEUR, height: HAUTEUR }}
        // touch-action-none : sans cette regle, le doigt fait defiler la page
        // au lieu de dessiner. Une ligne, et le pave devient utilisable sur
        // telephone.
        className="max-w-full cursor-crosshair touch-none rounded-[--radius-carte] border-2 border-dashed border-filet bg-white"
        onPointerDown={commencer}
        onPointerMove={tracer}
        onPointerUp={() => {
          traceEnCours.current = false;
        }}
        onPointerLeave={() => {
          traceEnCours.current = false;
        }}
        role="img"
        aria-label="Zone de signature : tracez avec la souris ou le doigt"
      />

      <div className="flex flex-wrap gap-2">
        <Bouton
          variante="secondaire"
          taille="sm"
          onClick={effacer}
          disabled={vide}
          icone={<Eraser className="size-4" aria-hidden="true" />}
        >
          Effacer
        </Bouton>

        <Bouton
          taille="sm"
          onClick={() => void enregistrerTrace()}
          disabled={vide}
          chargement={mutation.isPending}
          icone={<Save className="size-4" aria-hidden="true" />}
        >
          Enregistrer le trace
        </Bouton>

        <input
          ref={champFichier}
          type="file"
          accept={TYPES_ACCEPTES.join(',')}
          onChange={chargerImage}
          hidden
        />
        <Bouton
          variante="secondaire"
          taille="sm"
          chargement={envoiFichier}
          onClick={() => champFichier.current?.click()}
          icone={<Upload className="size-4" aria-hidden="true" />}
        >
          Charger une image
        </Bouton>
      </div>

      {erreur && <MessageErreur>{erreur}</MessageErreur>}
    </div>
  );
}

import { useEffect, useState } from 'react';

import { chargerImage } from '@/shared/api/client';

interface Etat {
  /** Le chemin auquel ce resultat correspond. */
  pour: string | null;
  url: string | null;
  echec: boolean;
}

const VIDE: Etat = { pour: null, url: null, echec: false };

/**
 * Affiche une image servie par une route protegee.
 *
 * <img src="/api/v1/.../photo"> ne fonctionne pas : le navigateur n ajoute
 * pas l en-tete Authorization sur le chargement d une image. On recupere donc
 * le binaire, et on en fait une URL temporaire (blob:...).
 *
 * Le nettoyage n est pas facultatif : chaque URL creee occupe la memoire du
 * navigateur jusqu a revokeObjectURL. Sur une grille de deux cents portraits
 * parcourue plusieurs fois, l oubli se voit.
 *
 * Detail de conception : le resultat porte LE CHEMIN auquel il correspond.
 * Cela evite de remettre l etat a zero depuis un effet — ce qui declencherait
 * un rendu de plus et afficherait brievement l ancienne image sous le nouveau
 * nom. Ici, un resultat qui ne correspond pas au chemin demande est
 * simplement considere comme perime, pendant le rendu, sans toucher a l etat.
 */
export function useImageProtegee(chemin: string | null): { url: string | null; echec: boolean } {
  const [etat, setEtat] = useState<Etat>(VIDE);

  useEffect(() => {
    if (!chemin) return;

    let annule = false;
    let creee: string | null = null;

    chargerImage(chemin)
      .then((resultat) => {
        if (annule) {
          // Le composant a disparu pendant le telechargement : on libere tout
          // de suite, sinon cette URL ne le sera jamais.
          URL.revokeObjectURL(resultat);
          return;
        }
        creee = resultat;
        setEtat({ pour: chemin, url: resultat, echec: false });
      })
      .catch(() => {
        if (!annule) setEtat({ pour: chemin, url: null, echec: true });
      });

    return () => {
      annule = true;
      if (creee) URL.revokeObjectURL(creee);
    };
  }, [chemin]);

  const correspond = chemin !== null && etat.pour === chemin;

  return {
    url: correspond ? etat.url : null,
    echec: correspond ? etat.echec : false,
  };
}

/**
 * Ajoute la date de mise a jour a l adresse d une image (le backend ignore ce
 * parametre). Une nouvelle photo ou signature = une nouvelle adresse = un
 * nouveau telechargement ; sans cela, l ancienne image reste affichee.
 */
export function avecVersion(chemin: string, version?: string | null): string {
  return version ? `${chemin}?v=${encodeURIComponent(version)}` : chemin;
}

function SignatureEnregistree({ agentId, majAt }: { agentId: string; majAt: string | null }) {
  // La date de mise a jour dans l adresse : remplacer la signature change
  // l adresse, donc l image affichee. Sans elle, l ancienne restait a l ecran.
  const { url, echec } = useImageProtegee(
    avecVersion(`/organisation/agents/${agentId}/signature`, majAt),

  if (echec) return <p className="text-sm text-encre-douce">Signature illisible.</p>;
  if (!url) return <div className="h-20 w-60 animate-pulse rounded bg-filet/60" />;

  return (

function TeleverserPhoto({ agentId, majAt }: { agentId: string; majAt: string | null }) {
  const champ = useRef<HTMLInputElement>(null);
  const invalider = useInvalidationAgent(agentId);
  const [erreur, setErreur] = useState<string | null>(null);

  const envoi = useMutation({
    mutationFn: (fichier: File) => apiAgents.envoyerPhoto(agentId, fichier),
    onSuccess: () => invalider(),
  });

  async function surChoix(evenement: ChangeEvent<HTMLInputElement>) {
    const fichier = evenement.target.files?.[0];
    if (!fichier) return;

    setErreur(null);
    if (!['image/jpeg', 'image/png', 'image/webp'].includes(fichier.type)) {
      setErreur('Formats acceptes : JPEG, PNG ou WebP.');
      return;
    }
    if (fichier.size > 2 * 1024 * 1024) {
      setErreur('Photo trop lourde (2 Mio maximum).');
      return;
    }

    try {
      await envoi.mutateAsync(fichier);
    } catch (echec) {
      setErreur(messageLisible(echec));
    } finally {
      if (champ.current) champ.current.value = '';
    }
  }

  return (
    <div className="flex flex-col gap-2">
      <input
        ref={champ}
        type="file"
        accept="image/jpeg,image/png,image/webp"
        onChange={surChoix}
        hidden
      />
      <Bouton
        variante="secondaire"
        taille="sm"
        chargement={envoi.isPending}
        onClick={() => champ.current?.click()}
        icone={<ImageIcon className="size-4" aria-hidden="true" />}
      >
        Changer la photo
      </Bouton>
      <span className="text-xs text-encre-douce">
        JPEG, PNG ou WebP, 2 Mio maximum.
        {majAt ? ` Mise a jour le ${formaterDateHeure(majAt)}.` : ''}
      </span>
      {erreur && <MessageErreur>{erreur}</MessageErreur>}
    </div>
  );
}

import type { Edge, Node } from '@xyflow/react';

import type { NoeudOrganigramme } from './types';

export const LARGEUR_NOEUD = 220;
export const HAUTEUR_NOEUD = 76;
const ECART_HORIZONTAL = 32;
const ECART_VERTICAL = 96;

export interface DonneesNoeud extends Record<string, unknown> {
  libelle: string;
  sousTitre: string | null;
  code: string | null;
  niveau: NoeudOrganigramme['niveau'];
  effectif: number;
  estGerant: boolean;
  agentId: string | null;
  aPhoto: boolean;
  prenom: string;
  nom: string;
  /** Nombre d enfants dans l arbre COMPLET, replies compris. */
  nbEnfants: number;
  replie: boolean;
}

export interface Disposition {
  noeuds: Node<DonneesNoeud>[];
  liens: Edge[];
  largeur: number;
}

/**
 * Place l arbre dans le plan : un arbre -> des noeuds positionnes et des liens.
 *
 * Deux raisons de garder cette fonction a part, sans React ni ReactFlow dans
 * ses parametres :
 *  - elle se teste avec un simple objet en entree et des coordonnees en
 *    sortie, sans monter un composant ;
 *  - elle survit au changement de bibliotheque d affichage : seules les deux
 *    dernieres lignes, qui mettent en forme pour ReactFlow, seraient a
 *    reecrire.
 *
 * Algorithme (parcours en profondeur, dit "reingold-tilford simplifie") :
 *  1. une feuille occupe sa propre largeur ;
 *  2. un noeud ayant des enfants les place d abord cote a cote, puis se
 *     centre au-dessus d eux ;
 *  3. la profondeur donne l ordonnee.
 *
 * On obtient un arbre sans chevauchement, en un seul passage, parce que
 * chaque sous-arbre renvoie la largeur qu il a consommee.
 */
export function calculerDisposition(
  racine: NoeudOrganigramme,
  replies: ReadonlySet<string> = new Set(),
): Disposition {
  const noeuds: Node<DonneesNoeud>[] = [];
  const liens: Edge[] = [];

  /**
   * Place un sous-arbre a partir de l abscisse `depart` et renvoie la largeur
   * totale occupee. C est cette valeur de retour qui evite les chevauchements :
   * le frere suivant commence la ou le precedent s arrete.
   */
  function placer(noeud: NoeudOrganigramme, depart: number, profondeur: number): number {
    const y = profondeur * (HAUTEUR_NOEUD + ECART_VERTICAL);

    // Le pliage est un etat d AFFICHAGE : il n est pas applique a l arbre
    // recu, qui reste intact dans le cache. On se contente de ne pas
    // descendre — rouvrir une branche n exige donc aucun nouvel appel.
    const enfants = replies.has(noeud.id) ? [] : noeud.enfants;

    let largeurOccupee = 0;

    // Seuls le premier et le dernier centre servent au calcul : les garder
    // dans deux variables evite un tableau dont il faudrait ensuite prouver
    // a TypeScript que les deux bouts existent.
    let premierCentre: number | null = null;
    let dernierCentre = 0;

    for (const enfant of enfants) {
      const largeurEnfant = placer(enfant, depart + largeurOccupee, profondeur + 1);
      dernierCentre = depart + largeurOccupee + largeurEnfant / 2;
      premierCentre ??= dernierCentre;
      largeurOccupee += largeurEnfant + ECART_HORIZONTAL;
    }

    // Le dernier enfant n a pas de frere apres lui : son ecart est en trop.
    if (largeurOccupee > 0) largeurOccupee -= ECART_HORIZONTAL;

    const largeur = Math.max(LARGEUR_NOEUD, largeurOccupee);

    // Un parent se centre sur ses enfants ; une feuille se centre sur sa
    // propre largeur.
    const centre =
      premierCentre !== null ? (premierCentre + dernierCentre) / 2 : depart + largeur / 2;

    noeuds.push({
      id: noeud.id,
      type: 'organisation',
      position: { x: centre - LARGEUR_NOEUD / 2, y },
      // Dimensions annoncees a l avance. Sans elles, ReactFlow doit d abord
      // dessiner chaque noeud pour le mesurer : le recadrage initial porte
      // alors sur des bornes incompletes — la racine sort du cadre — et la
      // mini-carte n a rien a dessiner.
      width: LARGEUR_NOEUD,
      height: HAUTEUR_NOEUD,
      data: donnees(noeud, replies),
      // Les noeuds ne sont pas deplacables : l organigramme est une lecture
      // de la base, pas un dessin libre. Autoriser le glissement laisserait
      // croire que la position se sauvegarde.
      draggable: false,
    });

    for (const enfant of enfants) {
      liens.push({
        id: `${noeud.id}--${enfant.id}`,
        source: noeud.id,
        target: enfant.id,
        type: 'smoothstep',
        style: { stroke: '#d3d9df', strokeWidth: 1.5 },
      });
    }

    return largeur;
  }

  const largeur = placer(racine, 0, 0);
  return { noeuds, liens, largeur };
}

function donnees(noeud: NoeudOrganigramme, replies: ReadonlySet<string>): DonneesNoeud {
  // Un noeud agent porte un nom complet "Prenom Nom" ; les initiales de
  // substitution ont besoin des deux morceaux separement.
  const [prenom = '', ...reste] = noeud.libelle.split(' ');

  return {
    libelle: noeud.libelle,
    sousTitre: noeud.sousTitre ?? noeud.fonction ?? null,
    code: noeud.code ?? null,
    niveau: noeud.niveau,
    effectif: noeud.effectif,
    estGerant: Boolean(noeud.estGerant),
    agentId: noeud.niveau === 'AGENT' ? noeud.id : null,
    aPhoto: Boolean(noeud.photoFichier),
    prenom,
    nom: reste.join(' '),
    nbEnfants: noeud.enfants.length,
    replie: replies.has(noeud.id),
  };
}

const TYPES_NOEUDS = { organisation: NoeudOrganisation };

function VueOrganigramme() {
  const { filtres, definir } = useFiltresUrl({ inclureAgents: 'true', seulementActifs: 'true' });

  /**
   * Branches repliees, par identifiant.
   *
   * Cet etat appartient a l ECRAN, pas au serveur : il ne passe donc pas par
   * TanStack Query. Melanger les deux obligerait a reecrire le cache a chaque
   * clic sur un chevron, pour une information qui n a aucun sens hors de
   * cette page.
   */
  const [replies, setReplies] = useState<ReadonlySet<string>>(new Set());

  const basculerBranche = useCallback((id: string) => {
    setReplies((actuelles) => {
      // On recree un ensemble au lieu de modifier celui en place : React
      // compare les references pour decider de redessiner. Un Set modifie
      // sur place reste le meme objet, et l ecran ne bouge pas.
      const suivantes = new Set(actuelles);
      if (!suivantes.delete(id)) suivantes.add(id);
      return suivantes;
    });
  }, []);

  const requete = useOrganigramme(filtres);

  /**
   * Le calcul de disposition est memoise sur l arbre.
   *
   * Il parcourt tout l arbre : le refaire a chaque rendu — au moindre
   * mouvement de souris sur le canevas — rendrait l ecran saccade sur une
   * filiale de deux cents agents.
   */
  const disposition = useMemo(
    () => (requete.data ? calculerDisposition(requete.data, replies) : null),
    [requete.data, replies],
  );

  const { fitView } = useReactFlow();

  /**
   * Recadrage apres CHAQUE changement d arbre (passage a une date du passe,
   * agents masques...).
   *
   * Le premier cadrage, lui, est confie a la propriete `fitView` du canevas
   * plus bas : a l instant ou cet effet s execute pour la premiere fois, le
   * canevas vient tout juste d etre monte et sa reserve interne de noeuds est
   * encore vide — l appel partirait dans le vide, sans la moindre erreur pour
   * le signaler. C est un piege classique : la fonction existe, elle ne
   * refuse rien, et pourtant rien ne bouge.
   */
  useEffect(() => {
    if (!disposition) return;

    // Laisser passer une image : le canevas a alors pris connaissance des
    // nouveaux noeuds.
    const minuteur = window.setTimeout(() => {
      void fitView({ padding: 0.15, maxZoom: 1, duration: 400 });
    }, 0);

    return () => window.clearTimeout(minuteur);
  }, [disposition, fitView]);

  return (
    <>
      <EnTetePage
        titre="Organigramme"
        sousTitre={
          filtres.dateReference
            ? `Organisation telle qu elle etait au ${formaterDate(filtres.dateReference)}`
            : "Organisation d aujourd hui"
        }
        actions={
          <BoutonsExport
            formats={['pdf', 'xlsx']}
            onExport={(format) =>
              apiOrganigramme.exporter(filtres, format === 'csv' ? 'xlsx' : format)
            }
          />
        }
      />

      <div className="carte mb-4 flex flex-wrap items-end gap-4 p-4">
        <label className="flex flex-col gap-1 text-sm font-semibold" htmlFor="orga-date">
          <span className="flex items-center gap-1.5">
            <CalendarClock className="size-4 text-dayo-bleu" aria-hidden="true" />
            Organigramme a la date du
          </span>
          <input
            id="orga-date"
            type="date"
            value={filtres.dateReference ?? ''}
            // L historique des postes permet de remonter dans le temps :
            // l arbre est alors reconstitue a partir des affectations ouvertes
            // ce jour-la, et non des rattachements actuels.
            onChange={(evenement) => definir('dateReference', evenement.target.value || null)}
            className="h-9 rounded-md border border-filet px-3 text-sm font-normal"
          />
        </label>

        {replies.size > 0 ? (
          <Bouton
            variante="secondaire"
            taille="sm"
            className="mb-0.5"
            onClick={() => setReplies(new Set())}
            icone={<Maximize2 className="size-4" aria-hidden="true" />}
          >
            Tout deplier
          </Bouton>
        ) : (
          <Bouton
            variante="secondaire"
            taille="sm"
            className="mb-0.5"
            onClick={() =>
              setReplies(
                new Set(
                  (disposition?.noeuds ?? [])
                    .filter((n) => n.data.niveau === 'DEPARTEMENT')
                    .map((n) => n.id),
                ),
              )
            }
            icone={<Minimize2 className="size-4" aria-hidden="true" />}
          >
            Replier les departements
          </Bouton>
        )}

        {filtres.dateReference && (
          <Bouton
            variante="secondaire"
            taille="sm"
            className="mb-0.5"
            onClick={() => definir('dateReference', null)}
            icone={<RotateCcw className="size-4" aria-hidden="true" />}
          >
            Revenir a aujourd hui
          </Bouton>
        )}

        <label className="flex items-center gap-2 pb-2 text-sm">
          <input
            type="checkbox"
            checked={filtres.inclureAgents !== 'false'}
            onChange={(evenement) =>
              definir('inclureAgents', evenement.target.checked ? 'true' : 'false')
            }
            className="size-4"
          />
          Descendre jusqu aux agents
        </label>

        <label className="flex items-center gap-2 pb-2 text-sm">
          <input
            type="checkbox"
            checked={filtres.seulementActifs !== 'false'}
            onChange={(evenement) =>
              definir('seulementActifs', evenement.target.checked ? 'true' : 'false')
            }
            className="size-4"
          />
          Masquer les entites desactivees
        </label>
      </div>

      {requete.isLoading && (
        <div className="carte p-6" aria-busy="true">
          <Squelette lignes={6} />
        </div>
      )}
      {requete.isError && <MessageErreur erreur={requete.error} />}

      {disposition && (
        <div className="carte h-[70vh] overflow-hidden p-0">
          <ReactFlow
            nodes={disposition.noeuds}
            edges={disposition.liens}
            nodeTypes={TYPES_NOEUDS}
            fitView
            // maxZoom : sur un arbre reduit — une seule branche depliee — le
            // cadrage grossirait les cartes jusqu a l absurde.
            fitViewOptions={{ padding: 0.15, maxZoom: 1 }}
            onNodeClick={(_evenement, noeud) => {
              const donnees = noeud.data as DonneesNoeud;
              // Un agent n a pas d enfants : son noeud est un lien vers la
              // fiche, et le clic ne doit pas etre detourne.
              if (donnees.niveau !== 'AGENT' && donnees.nbEnfants > 0) {
                basculerBranche(noeud.id);
              }
            }}
            // Positions calculees par nous : la bibliotheque ne doit ni les
            // recalculer ni les laisser modifier.
            nodesDraggable={false}
            nodesConnectable={false}
            elementsSelectable={false}
            proOptions={{ hideAttribution: false }}
            minZoom={0.2}
            maxZoom={1.6}
          >
            <Background gap={24} color="#e3e8ee" />
            <Controls showInteractive={false} />
            <MiniMap pannable zoomable className="!bg-fond" />
          </ReactFlow>
        </div>
      )}
    </>
  );
}
